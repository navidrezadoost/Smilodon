# Android control application for 178-F.2

This standalone React Native `0.76.9` control app uses React Native WebView `13.12.5` and contains no Smilodon dependency. Its simple HTML list and native controls provide a matched mount, WebView, search, selection, screenshot, hierarchy, ADB, and logcat workload against the packed Smilodon fixture.

The controlled comparison builds this app and the packed Smilodon consumer with the same Node, npm, Java, Gradle, API 35 emulator image, and WebView dependency. The app is diagnostic control evidence only; passing it does not certify Smilodon or the native bridge suite.
