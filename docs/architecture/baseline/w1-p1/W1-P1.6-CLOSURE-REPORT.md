## 1. Scope of this closure

W1-P1.6 set out to characterize, through the **public package surface only**, the **security / CSP utility exports** and their **server-side (no-DOM) behavior** — the surfaces the ledger deferred to P1.6 as *documented-only, not certified* (ledger §10/§12). At P1.5 closure this surface had **zero** registered contract IDs.

P1.6 defined and registered **17 P1.6-targeted contracts** across two public utility modules and the package entry:

1. **Security / HTML-safety utilities** — `packages/core/src/utils/security.ts`: sanitizer registry/boundary (`setHTMLSanitizer`, `getHTMLSanitizer`, `sanitizeHTML`, `validateTemplate`); safe DOM construction (`createElement`, `createTextNode`, `setTextContent`, `setCSSProperties`); escaping/detection (`escapeHTML`, `escapeAttribute`, `containsSuspiciousPatterns`); environment capability detection (`CSPFeatures`, `detectEnvironment`).
2. **CSP-compliant styling utilities** — `packages/core/src/utils/csp-styles.ts`: `applyClasses`, `toggleClass`, custom-property family, `defaultTheme`/`applyDefaultTheme`/`shadowDOMStyles`, `injectShadowStyles`, `hasOverflowHiddenAncestor`, `warnCSPViolation`.
3. **SSR / import-time safety** — whether the public exports import in a Node (no-DOM) environment without throwing at import time, and whether DOM-dependent functions defer browser access to **call time**.

Task 4 consolidates the accepted implementation increments (Tasks 1, 1-R, 1-R1, 2, 2-R, 2-R1, 3, 3-R) into a single independently-reviewable statement, records final coverage for all 17 contracts, dispositions the residual gaps, and bounds what has **not** been proven.

This closure **does not** re-characterize behavior, **does not** repair anything, **does not** change any classification beyond what Tasks 1–3 committed, and **does not** authorize production remediation, ADR, or Angular work.

## 5. What was CERTIFIED vs NOT certified

### 5.1 Certified (observed, public-surface, deterministic)

- **Security utilities** (API-063..069, CONFIG-027..028): sanitizer registry/boundary semantics; safe construction (`createElement`/`createTextNode`/`setTextContent`/`setCSSProperties`); escaping/detection; `CSPFeatures` predicates return boolean without throwing; `detectEnvironment` shape; `getCSPDirectives` reads CSP meta-tag content (`[]` when none).
- **CSP styling utilities** (API-070..074, CONFIG-029): class application/toggle; custom-property set/get/remove (with the **documented prefix asymmetry**); `defaultTheme` exact 13-entry map; `applyDefaultTheme`; `shadowDOMStyles` static string (no `<script>`); `injectShadowStyles` additive; `hasOverflowHiddenAncestor` parent-chain/body-excluded; `warnCSPViolation` dev-only.
- **SSR boundary** (API-075/076): the two utility modules import in a no-DOM Node process; DOM-dependent helpers (`escapeHTML`, `createElement`) access `document` at **call time** (throw `ReferenceError: document is not defined`), not import time.

### 5.2 NOT certified / open limitations

| Item | Disposition | Detail |
| --- | --- | --- |
| **API-065** — case-sensitive `on*`/`style` filtering | **Open production security limitation** | `createElement` blocks case-sensitively; `ONCLICK`/`OnLoad`/`Style`/`STYLE` bypass to live handler/inline style. Characterized only; remediation needs separate production authorization. |
| **API-075** — package-entry SSR import failure | **Open production compatibility limitation** | `index.ts` import **throws** `ReferenceError: HTMLElement is not defined` in no-DOM Node (web components `extend HTMLElement` at class-declaration time). Remediation needs separate production authorization. |
| **API-076** — deferred DOM access | **Certified only for tested utility functions** | Existing applies to the specifically tested helpers, not every DOM-dependent export. |

| Browser CSP enforcement | **Not certified** | Production-**conditioned source** behavior exercised; compatibility with an enforced browser CSP not certified. |
| Framework hydration / adapters | **Not certified** | Adapter SSR/hydration out of W1-P1 scope. |
