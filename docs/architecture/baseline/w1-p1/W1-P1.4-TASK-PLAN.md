## 6. Acceptance criteria (per contract)
A contract is eligible for `Existing` only when **all** hold:
- AC-1: Covered via **public surface only** (no `_private` access; harness-integrity test asserts this, as in P1.3).
- AC-2: Assertion observes the contract's **externally observable** effect (attribute/part/event/lifecycle/DOM), not an internal field.
- AC-3: **Negative path** included where the wiring implies one (e.g., `data-custom-arrow` removed on slot unassign; part absent in mode where it should be; reconnect without duplicate).
- AC-4: Test is **deterministic** and does not depend on timing beyond explicit `await`/events; no flake retries used to pass.
- AC-5: Traceability `evidence` field points to the exact test ID.

**Increment-level acceptance:**
- All 21 contracts at AC-1..AC-5, OR explicitly reclassified (see §7) with Lead-approved justification.
- Full core suite green (expected ≥ 922 + new), focused Chromium suites green.
- `verify_traceability.py` PASS; distribution recalculated and reconciled (no silent reclassification).
- Production isolation: `git diff` of `packages/core/src packages/core/engine packages/core/adapters` vs the fork point is **empty**.
- Accepted P1.3 tests unchanged.
- Checksums verify.

## 7. Pre-identified risks & classification risks
1. **CONFIG-023 `expandable` — likely NOT wired in core component.** Planning grep shows it exists only in `global-config.ts` defaults, with **no reference in `enhanced-select.ts`**. Therefore a public black-box test may observe *no effect*. **Plan:** T3 first proves current behavior; if confirmed unwired, CONFIG-023 is **reclassified as a documented gap/deviation candidate (not silently marked Existing)** and raised to the Lead — it may belong to a future feature-design increment, not characterization. This is the single highest-uncertainty contract and is called out now to avoid surprise at closure.
2. **ATTR-013 `style.display='block'` forced** is an Angular-motivated behavior (DEVIATION-05). Test characterizes the *forced* value as observed; it does not endorse it.
3. **ATTR-021 data-motion closing** depends on exit-animation duration; test must set `data-motion`/config deterministically and assert the transient attribute without relying on wall-clock flake.
4. **Part tokens** are asserted as `[part="…"]` attributes present in rendered tree; owned-shadow vs light-DOM placement verified per locator before writing assertions.
